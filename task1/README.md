# Simple Task Manager

## Overview

Simple Task Manager is a web-based application developed using HTML, CSS, and JavaScript. It helps users manage their daily tasks efficiently by allowing them to add, complete, and delete tasks.

## Features

### Add Task

* Enter a task in the input field.
* Click the **Add Task** button to add the task.
* Press the **Enter** key to add the task quickly.

### View Tasks

* All added tasks are displayed in a list format.

### Complete Task

* Click the **Complete** button to mark a task as completed.
* Completed tasks are displayed with a strikethrough effect.

### Delete Task

* Click the **Delete** button to remove a task from the list.
